# 🎬 BurmaldaCutter

**Локальный AI-генератор вертикальных клипов для Shorts / Reels / TikTok — бесплатный аналог Opus Clip.**

Нарезает длинный стрим на готовые вертикальные клипы: сам находит сильные моменты, вырезает рекламу, следит за лицом в кадре, рисует караоке-субтитры и выравнивает звук. Всё считается на вашем компьютере — видео никуда не загружается.

## 🚀 Возможности

### 🧠 Нейросетевой кроп и веб-камера
- **Автоцентр веб-камеры по лицу** — локальная модель YuNet (232 КБ, лежит в репозитории) находит стримера и наводит рамку сама.
- **Позиции**: четыре угла + «по центру слева / справа» (зона = треть экрана, по вертикали 20–80 % кадра).
- **Зум 1.0–2.2× и смещения X/Y** — чтобы отрезать шапку браузера, рамки OBS и лишний фон.
- **Рефрейм основного кадра**: камера ведёт лицо (или группу лиц) с мёртвой зоной и сглаживанием — без дёрганья на микродвижениях головы; нет лиц → нейтральный центр.
- Если камера включена, а лица в кадре нет (полноэкранная вставка, заставка) — клип сам рендерится обычным кропом, а не пустой полосой интерфейса.

### 💬 Pro-субтитры (ASS)
- Karaoke-подсветка: произносимое слово горит акцентом и «подпрыгивает» (`\t`), остальные — белые с жирной обводкой и мягкой тенью.
- Умный перенос в **1–2 сбалансированные строки** (12–22 символа), а не «по три слова» — длинные русские слова не разъезжаются от края до края.
- Три пресета: **Hormozi (жёлтый)**, **Неон (зелёный)**, **Чистый белый с тенью** + слайдер размера шрифта и отступа снизу (safe-zone под баннеры).

### 🎯 Умный отбор моментов и отсев рекламы
- Кандидаты собираются **по границам фраз Whisper**, а не по случайным паузам посреди предложения.
- **LLM-оценка вирусности** (хук в первые 3 секунды, законченная мысль, эмоция/инсайт) + короткий **заголовок клипа** на русском.
- **Вырезание рекламы**: модель видит контекст ±20 секунд, помечает интеграции, подводки («сразу после небольшой рекламной интеграции»), промокоды, ссылки и заставки; плюс мгновенный стоп-фильтр по фразам — до всякой нейросети.
- Провайдер меняется в два клика: **локальная Ollama (qwen3)** без интернета и лимитов, либо облачные **Groq / Cerebras / Gemini** по OpenAI-совместимому API.
- Нет ключа, кончилась квота, упала сеть — плавный откат на встроенный математический скоринг с понятным предупреждением в ленте.

### 🔊 Звук и картинка
- **Двухпроходная нормализация громкости** `loudnorm` до **−14 LUFS** (TP −1.5): клипы звучат одинаково плотно.
- **Мягкий хвост +0.6 с** после последнего слова — фраза не обрывается на полуслове.
- `setsar=1` и `+faststart`: честные 9:16 без кривого SAR, мгновенный старт в браузере и соцсетях.

### ⚡ Скорость
- **Кэш анализа** в `.cache/`: Whisper, RMS и карта движения считаются один раз на файл — повторный прогон с другими настройками стартует за секунды.
- Карта движения по ключевым кадрам (`-skip_frame nokey`) — декод в ~9 раз быстрее полного.
- Реальный прогресс рендера из `-progress pipe:1`, а не «крутилка на удачу».
- Живая лента: клипы появляются по одному сразу после рендера.
- Автоуборка: `gradio_tmp` старше суток, `.cache` старше 30 дней.

## ⚡ Быстрый старт (Windows)

### 1. Python 3.12
Скачайте с [python.org](https://www.python.org/downloads/) и при установке **обязательно** отметьте `Add python.exe to PATH`.

### 2. FFmpeg
Возьмите сборку `ffmpeg-release-essentials.zip` с [gyan.dev](https://www.gyan.dev/ffmpeg/builds/), распакуйте и положите **`ffmpeg.exe` рядом с `app.py`** (в корень проекта). `ffprobe.exe` не нужен.

> Если `ffmpeg.exe` не положить, приложение попробует взять `ffmpeg` из `PATH`.

### 3. Виртуальное окружение и зависимости
```bat
cd путь\к\BurmaldaCutter
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```
Папка окружения должна называться именно `.venv` — на неё рассчитан `run.bat`.

### 4. Запуск
Дважды кликните **`run.bat`** (или `.venv\Scripts\python.exe app.py`).
Откроется `http://127.0.0.1:7860`.

Загрузите видео (или укажите полный путь к файлу на диске — для многочасовых стримов это быстрее и надёжнее), нажмите **«⚡ Нарезать клипы»**, готовые файлы появятся в `output/`.

> Первый запуск скачает модель Whisper `small` (~500 МБ) — дальше она берётся из кеша.

## 🤖 LLM-отбор моментов

Работает и без интернета, и с облаком — переключается в аккордеоне **«🤖 LLM-отбор моментов»**.

### Вариант A — локальная Ollama (без лимитов и ключей)
```bat
winget install Ollama.Ollama
ollama pull qwen3:4b
```
В UI: **Провайдер → Ollama локальная**, модель `qwen3:4b`, ключ оставить пустым.
Запросы идут на `http://localhost:11434` и никуда не уходят.

### Вариант B — облачные провайдеры (быстрее и умнее)
1. Скопируйте `.env.example` → `.env`.
2. Вставьте ключ нужного провайдера:

| Провайдер | Где взять ключ | Модель по умолчанию |
|---|---|---|
| Groq | [console.groq.com/keys](https://console.groq.com/keys) | `llama-3.3-70b-versatile` |
| Cerebras | [cloud.cerebras.ai](https://cloud.cerebras.ai/) | `llama-3.3-70b` |
| Google Gemini | [aistudio.google.com](https://aistudio.google.com/app/apikey) | `gemini-2.5-flash` |

3. Выберите провайдера в списке — модель, Base URL и ключ подставятся сами.

Ключ можно вставить и прямо в поле UI (оно `password`). Приоритет: **UI → переменная окружения → `.env`**.

## ⚙️ Как это работает

```
видео → копия в temp
      → анализ: RMS звука + карта движения + Whisper (слова, сегменты)   [кэш по отпечатку файла]
      → кандидаты по границам фраз (LLM) или по паузам (математика)
      → LLM: контекст ±20 с, score / is_ad / title, один запрос на ролик [кэш вердиктов]
      → рендер: кроп по лицам (YuNet) → ASS-субтитры → loudnorm −14 LUFS → x264
      → карточки в ленте + файлы в output/
```

## 🔧 Полезные параметры UI

| Параметр | Зачем |
|---|---|
| **Формат клипа** | 9:16, 4:5, 1:1, 16:9 |
| **Позиция веб-камеры** | угол или центральная зона исходника |
| **Зум вебки / смещения X, Y** | точная рамка вокруг лица, обрезка хрома браузера |
| **Автоцентр вебки по лицу** | YuNet сам наводит рамку |
| **Стиль и размер субтитров** | пресеты + кегль, MarginV под баннеры |
| **Порог сочности** | работает в математическом режиме; с LLM заменяется моделью |
| **Максимум клипов** | 0 — без ограничений |
| **Интервал** | обрабатывать только кусок `01:20–15:00` |

Тонкая настройка — константы в начале `app.py`: `CLIP_TAIL_SECONDS`, `FACE_DEAD_ZONE`, `FACE_SMOOTHING`, `AUDIO_LOUDNORM`, `LLM_*`, `WEBCAM_*`.

## 📝 Заметки и ограничения

- Проверено на **Windows 10/11**; Linux/macOS скорее всего заведутся, но не тестировались.
- Кодирование **только CPU (libx264)** — сознательно, ради предсказуемости и качества.
- `loudnorm` целится в −14 LUFS; на очень «пиковом» игровом аудио результат может быть около −16 LUFS при TP −1.5 — это потолок без клиппинга. Клипы при этом выровнены между собой.
- Распознавание речи настроено на **русский** (`language="ru"`, модель `small`); язык и модель меняются в `transcribe_audio()`.
- Отсев рекламы — эвристика + LLM: на нестандартных интеграциях возможны промахи, проверяйте ленту перед публикацией.
